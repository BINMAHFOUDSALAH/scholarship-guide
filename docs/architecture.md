# Architecture

How واضح is put together. Why each choice was made lives in [decisions.md](decisions.md).

## Big picture

```
Browser ──request──▶ FastAPI app (app/main.py) ──reads──▶ data/*.json     (facts, settings)
   ▲                        │                            content/**/*.md (page text)
   └──── HTML page ─────────┘ uses templates/ (Jinja2, RTL) + static/ (CSS, JS, fonts, images)
```

Server-rendered pages, no frontend framework. GitHub → Render deploys on push (only after CI passes).

## App (`app/`)
- `main.py`: the FastAPI app. A middleware sends the old Render address and `www` to `base_url` with a 301 (decision 042). Loads `data/*.json` once at startup with `load_json()` (data changes need a server restart). Exposes `site` (from `data/site.json`) to every template as a Jinja global, plus the `arabic_date` filter (`2026-10-09` → `9 أكتوبر 2026`) and the `count_ar` filter (`5 | count_ar("universities")` → «5 جامعات», Arabic counting rules). Routes: `/`, `/news`, `/about`, `/grades/{slug}`, `/programs/{slug}`, `/resources/{slug}`, `/universities`, `/universities/{id}` (optional `from` = the search to link back to), `/my-list` («قائمتي»; `?partial=1&ids=a,b` returns its rows for known ids only), `/api/universities`, `/api/suggestions`, `/robots.txt`, `/sitemap.xml`; unknown pages raise 404 → Arabic `404.html`. `TRACK_STATUS_LABELS` (status → Arabic label) is a Jinja global. `program_slugs()` = programs that have both a `paths.json` entry and `content/programs/<id>.md`. `is_confirmed()` filters news: only items with `source_url` or `owner_confirmed` are shown. `track_status(track)` (Jinja global) gives today's status: واعد follows `waaid()` (latest programs, open/closed computed from dates); an open track with `status_until` closes itself after that date. `program_targets` maps university ids to programs that target them (SDAIA). `status_board()` builds the news board (open / waiting / recent) from `paths.json` track statuses + `waaid()` (decision 033); `partials/status_board.html` renders it on `/` (4 per group) and `/news` (all). `Explorer.target_programs` / `targets_of` power the «برامج إضافية» filter (`target=` query param).
- `sort_news()`: publication date, newest first; on the same date opening → deadline → closing → announcement.
- `universities.py`: the explorer. `Explorer` loads `data/universities.json`, `university_names_ar.json`, `countries.json`, and `university_details/*.json` once at startup; `search()` returns sections of rows in three modes (major / name / browse); `describe(result)` turns a search into the applied-filter tags (each with a link that removes it), a one-line summary for the screen-reader status, and the query carried on result links; `back_url(raw)` rebuilds the explorer link from a university page's `from` parameter, keeping only known parameters and values; `key_facts(uid)` is a result row's at-a-glance line; `next_deadline(uid)` skips `reference_only` dates; `sat_summary(track)` and `upcoming_deadlines()` feed the grade pages; `normalize()` makes search forgiving (أ/إ/آ, ة/ه, ى/ي, accents, case).
- `content.py`: `load_page(section, slug)` reads `content/<section>/<slug>.md` (frontmatter + Markdown → HTML) on every request; headings get ids (the `toc` extension, Arabic kept; a heading can set a short one with `{#id}`) and `contents` lists the h2s for «في هذه الصفحة», so content edits need no restart. The slug must match `^[a-z0-9-]+$`, so URLs can never reach other files. `list_slugs()` feeds the sitemap.
- `WADIH_SHOW_DRAFTS=1` (local only, never on Render) shows unverified drafts such as the Tuwaiq section.

## Data (`data/`)
- `site.json`: name, descriptor, tagline, `base_url` (the one place to change when the custom domain arrives), description.
- `paths.json` (shown as «البرامج»): each program has `id`, `theme` (world/desert/sea), `photo` (or `null` → drawn scene), optional `logo` (official, self-hosted, with `source_url`/`asset_url`/`retrieved`; shown instead of a photo), names, `provider_ar`, `audience_ar` («لمن؟»), summary, official/apply/universities links, `verified`, optional `facts`, and `tracks` (`status`: open/closed/not_open/invitation/none_open, or `null` only when `for_high_school` is false; `status_source`, `owner_confirmed`, `last_checked`; a status shows only with a source or owner confirmation). Converted tracks also have `id`, `name_en`, `levels_ar`, `for_high_school`, `high_school_ar`, `admission_ar`, `facts`.
- **Fact shape** (decision 025), used in `facts` lists: `id`, `text_ar`, `sources` [{`title`, `url`}], `last_checked`, `academic_year`, `status` (sourced/unverified/conflict/outdated), `owner_reviewed`, `note_ar`. Rendered only through the `fact` macro.
- `waaid_programs.json`: the latest واعد programs (from the Ministry's واعد page), shown in a toggle under the واعد track (`partials/waaid_programs.html`). Add new programs at the top.
- `news.json` (announcements only since decision 033; statuses come from `paths.json`): `added` (when we added it; ordering only, never shown), `type` (opening/closing/deadline/announcement), `path_id`, `title_ar`, `source_url`, optional `page` (our own explainer, linked instead of the source), `owner_confirmed`. The homepage shows the newest 3 confirmed items.
- `apply_year.json`: ثالث ثانوي month by month (decision 040). `rows` cover every month once (`months`), each with an action and «موعد رسمي» facts with sources. A row with `computed` shows a pattern counted by `Explorer.timeline_stats()`. The row for today's month is marked «الآن» and lists `Explorer.upcoming_deadlines()`. A `scholarship` block holds the unconditional-offer rule and the timing conflict; the current الرواد status comes from `paths.json`.
- `school_tracks.json`: the five secondary-school tracks for the grade 10 page (Ministry 2025 document, pp. 11–15).
- `test_needs.json`: «الاختبارات: من يطلب ماذا؟» on the grade 11 and 12 pages. One row per destination (Saudi universities, the King scholarship, Aramco, KGSP), each with its official source and `read_on` date. The الرواد row is `computed`: `Explorer.sat_summary()` counts SAT/ACT policies from `university_details/` (decision 038).
- `home.json`: homepage text: the lead, the three grade buttons (label + one-line hint), and the example searches under the homepage search (a major, a university id, or a track).
- `featured_quote.json`: the Tuwaiq quote; renders only when `status` is `verified` (or drafts are shown locally). Video via `youtube_id`.
- Trust rule (decision 028): a sourced fact shows its source link; anything without an official source or owner confirmation is hidden (no stamps on the site). Dates are ISO in data and not shown.

## Templates (`app/templates/`)
- `base.html`: `<html lang="ar" dir="rtl">`, head (description, canonical, Open Graph tags, light-first theme script), header, footer. Blocks: `hero` (full width), `content` (inside `.container`), `after_content` (full-width bands like `partials/tuwaiq.html`), `scripts` (page-only JS such as `video.js`), `title`, `description`.
- The nav links are one Jinja list (`nav_links`) used by the desktop nav and the phone `<details>` menu (the footer has no link list since 2026-10-11: brand, independence line, «كيف نتحقق؟», the owner's X icon); the current section gets `aria-current` ("page" on the page itself, "true" inside its section). Also in `base.html`: the skip link to `<main id="main">`, the «قائمتي» header link (always visible since decision 039; `mylist.js` adds the count), a global `role="status"` line for save announcements, the footer's independence line, and `mylist.js` on every page. `head_extra` block: e.g. `noindex` on /my-list.
- `home.html` (decision 035: hero with the grade buttons and the search panel → «مفتوح للتقديم الآن» → programs → Tuwaiq band), `universities.html` + `partials/uni_results.html` (the explorer; the partial is also returned alone for live updates) + `partials/uni_macros.html` (university name, saved marker, notes, country with its official language, lists, `key_facts` (SAT/ACT · IELTS · next university date · admissions page, or «لم نجمعها بعد»), `date_words` / `date_short` for structured dates), `university.html` («باختصار» first, then lists, requirements, then «المواعيد»: the scholarship's window and the university's own dates as two separate blocks), `my_list.html` + `partials/my_list_rows.html` («قائمتي»), `news.html`, `grade.html` (the three grade pages, decision 040: the grade journey bar → «ما يهم هذه السنة» (3 points) → «ابدأ الآن» (`activity` in frontmatter) → the grade's own tool (`tool: tracks | tests | year`) → «لتعرف أكثر» → sources), `partials/school_tracks.html`, `partials/test_needs.html`, `partials/apply_year.html`, `page.html` (resource pages such as `/resources/ielts`, inside `.measure`), `program.html` (program page: header, track comparison table, sourced facts, then the Markdown from `content/programs/`), `about.html`, `404.html`.
- `components.html`: macros `path_steps`, `source_stamp(sources)`, `fact(f, label)`, `status_tag(status, until, label)` (the only way a status is drawn), `back_link(href, text)`, `next_step`.
- `partials/path-art.html`: the SVG macro `scene(theme)` (fallback when a program has no photo or logo). The homepage drawing was removed in decision 035.

- `universities.json` (generated by `scripts/extract_universities.py`; never edit by hand), `university_names_ar.json` (our Arabic translations), `countries.json` (Arabic name + whether English is official, from the program's country pages), `university_details/<id>.json` (requirements from each university's official site; schema in `docs/specs/universities-explorer.md`).
- `content/`: `grades/` (grade pages), `programs/` (one page per program), `resources/` (shared resources such as `ielts.md`).
- `data/raw/` (git-ignored): official source files we extract from, e.g. the universities guide PDF.

## Static (`app/static/`)
- `style.css`: design tokens at the top (light default; dark only via `data-theme="dark"`): colours with fixed meanings, one type scale (`--text-xs` … `--text-hero`, nothing under 13px), `--focus`, `--control-border`. Then the shared components (decision 035): `.btn` (`--primary` forest, `--secondary` outlined), `.status--*`, `.tag` / `.tag--warn` / `.tag--saved`, `.notice`, `.summary-list`, `.back-link`, `.rows`, `.field-label` / `.input` / `.select`. Mobile-first, logical properties (`padding-inline`, never left/right). `.container` = the wide grid (~1240px), `.page-wide` = tool pages (1040px), `.measure` = the 720px reading column. Tints use `color-mix()` on tokens. `[hidden]` always wins.
- `fonts.css` + `fonts/`: self-hosted IBM Plex Sans Arabic (400/600/700) and Noto Naskh Arabic (700), OFL.
- `theme.js` (light ↔ dark toggle, saved in `localStorage`), `video.js` (click-to-play: YouTube loads only after a click), `universities.js` (the search suggestions on the homepage and the explorer; the explorer's live results, filter tags, phone filter toggle, status line, error state; «الرجوع إلى نتائج البحث» via `history.back()`; the page works without it), `mylist.js` («قائمتي»: ids in `localStorage` under `wadih:saved`, one delegated click handler for every `[data-save]` button: the university page toggle and «احفظ» / «✓ في قائمتك» in result rows, including rows from live updates; the header count; the /my-list page; with storage blocked, no save buttons and a message on /my-list).
- `favicon.svg` = the logo mark (decision 036: ض with a lime diamond dot on a forest tile); the header draws the same SVG inline in `base.html`. `img/paths/*-500.jpg|960.jpg` (licensed photos; credits on /about), `img/programs/*-500.png|960.png` (official logos), `img/og-image.png` (share image; regenerate with `scripts/og-image.js` in the browser console).
- After CSS changes, browsers may serve a cached copy: hard-refresh with Ctrl+Shift+R.

## Tests (`tests/`)
- `test_pages.py`: pages load, 404s, slug safety, draft gating, nav, every homepage link works, share tags, robots/sitemap, no third-party requests, light-first theme.
- `test_data.py`: the trust rules as code (e.g. a path can't be `verified` unless every track status has a source; photos need credit and licence; every fact follows decision 025; a conflict needs both sources and a note).
- `test_content.py`: the Markdown loader.
- `test_universities.py`: the extracted lists (الرواد = 30, ranks continuous except documented gaps, notes kept), Arabic names, requirement-file schema, search modes and filters, applied-filter links, the `from` whitelist, Arabic counting, explorer and university pages, «قائمتي» rows, API, sitemap, and the browser normaliser's regex.
- `test_design.py`: the colour rules (WCAG contrast of every token pair in both themes, focus ring and input borders ≥ 3:1) and the type-scale floor.

## Scripts and specs
- `scripts/extract_universities.py` (+ `flag_countries.json`, `university_aliases.json`, `list_overrides.json`): rebuilds `data/universities.json` from the PDF in `data/raw/`. Run: `.venv\Scripts\python.exe scripts\extract_universities.py`. `pdfplumber` is dev only.
- `docs/specs/universities-explorer.md`: the explorer spec and the requirements schema.
- `marketing/src/` (decision 044): the launch ad, kept apart from the app. `capture_site.mjs` records the live site in headless Edge; `make_voice.py` calls ElevenLabs; `build_ad.py` assembles the videos with ffmpeg. Media lives in `marketing/assets/` and `marketing/out/` (git-ignored). Guide: `docs/marketing/launch-ad.md`.

## Tooling
- `.github/workflows/tests.yml`: runs `pytest` on every push and pull request (CI). Render deploys only after it passes.
- `.claude/settings.json`: a permission rule that blocks Claude from reading `.env`.
- `.claude/launch.json`: starts the dev server in the Claude desktop app's browser pane.
